# 四册数学教材 · 知识图谱

把《高等数学（上）》《高等数学（下）》《数学分析（上）》《数学分析（下）》四本教材整理成**一个可以检索、可以按章节点开、可以画成图谱、也可以按节速览要点**的单文件网页。附带一册「校订记录」，把通读时发现的 16 条问题逐条写清楚，并和教材正文互相跳转。

**在线查看：<https://glittery-fenglisu-e5d3ba.netlify.app>**

> 单文件、零外链、离线可用：下载 `index.html` 双击就能打开，断网照样能读、能搜、能画公式、能看精要。

## 功能

- **阅读**：按章 / 节 / 定理 / 例题切好的节点树，正文按原书页码打锚点（`p.223` 这类标记），读的时候仍能对上纸质书。
- **精要**：按小节给出「一个定义 + 若干定理 + 配套例题」，只留陈述、剔掉证明与解答，适合复习时快速扫一遍。每节可切「精简」（只列前 3 定理 / 前 3 例），每条都带「原文」跳回教材原位。
- **检索**：一个输入框同时搜四册，概念、定理名、关键词都能命中，回车直达。
- **图谱**：把一册的知识点画成章节泳道图，节点按「定义 / 定理 / 例 / 其他」着色，悬停看关联、点节点看原文。
- **公式**：KaTeX 0.16.22 全部内联（含 woff2 字体），6,282 条显示公式离线渲染；Markdown 管道表与 `array` 环境都转成真正的 HTML 表格。
- **双向跳转**：教材里被改过的段落顶部会出现赭色提示条，点条目号跳到「校订记录」对应条目；记录里的「位置：高等数学（上）· p.223」反过来点回教材，并精确滚到那一页。
- **阅读排版**：右上角 `Aa` 调字号、行距、栏宽（也可按 `?` 呼出，键盘 `+` / `-` 直接调）。
- **打印 / 另存 PDF**：点 `⎙` 或 ⌘P，自动隐藏顶栏、目录、翻页条，正文转单栏。
- **双主题**：浅色（暖白纸感）/ 深色，选择记在 localStorage。
- **窄屏可用**：三栏精要在 < 1000px 自动改为上下堆叠；顶栏按 1120 / 1000 / 860 三档收缩，不出横向滚动条。

## 校订记录

通读 44,463 条公式、557 条定理/定义/推论、约 890 道例题后，确认的问题分三类，共 16 条发现、18 个落点：

- **A 类 · 知识性错误（1 条，2 处）**：《高等数学（上）》p.223 定理 1、p.225 定理 2 的广义积分比较判别法，发散侧只写了 `k(<+∞)`，漏掉 `k>0` 这个下限。反例：`f(x)=1/x²` 时 `lim x f(x) = 0`，按原文条件会被判成发散，而 `∫₁^∞ dx/x² = 1` 收敛。同一册《数学分析（上）》p.268 / p.274 的推论 3 写法完整（收敛侧 `0 ⩽ λ < +∞`、发散侧 `0 < λ ⩽ +∞`），可对照。
- **B 类 · 结构缺陷（1 条）**：《数学分析（下）》p.237 极坐标二重积分公式缺收尾定界符 `$$`，导致后面一整段（含「(ii) 若原点为 D 的内点……」）被吞进公式里。
- **C 类 · 排印缺陷（14 条）**：公式环境内直接夹汉字未加 `\text{}`（13 处）、引用编号断字「定理 19. 11」→「19.11」（1 处）。

另有一批**复核后排除**的疑点（2,936 条「恒等式不成立」实为定义式、470 条 `\left/\right` 不配对实为逐行切分的假象等），以及**没有覆盖到的部分**（例题答案未逐题验算、图形与表格内文字的语义、教材本身的印刷错漏），都写在「校订记录 · 复核后排除的疑点 / 没有覆盖到的部分」两节里。

## 技术

- 单个 `index.html`（约 4.0 MB）：KaTeX 的 CSS/JS/woff2 字体全部 base64 内联，教材全文以 JSON 内嵌，无任何外部请求。
- 渲染器：自写 Markdown 子集（标题、列表、引用、管道表、`$$` 块级公式、行内 `$…$`、行内代码、粗斜体）+ 页面锚点 `<!-- p.N -->`。
- 精要视图的数据在浏览器里从节点树现抽（`digestOf`），不额外存副本；截断规则在 `cleanBody` / `tighten` 里：定理截到「证」、例题截到「解 / 分析」、再只留第一段，定义保留完整文字。
- 由本地 Python 流水线生成（解析 md → 建节点与概念索引 → 注入 KaTeX → 打包成单文件），修改内容后重新生成即可，不手改产物。构建链只用标准库。
